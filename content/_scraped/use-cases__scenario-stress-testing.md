## Simulations you can check and run again.
Code‑backed simulations. Every simulation runs in code, so each figure comes with the calculation behind it. Missing inputs are flagged. When an input is missing, the output flags it instead of inventing one. Re‑run any output. When the tape moves, you can re‑run the same analysis on the new data.
